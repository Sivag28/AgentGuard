# Active log data provenance

The active `data/logs.txt` file is an unmodified real CI build log from:

- Dataset: LogChunks, a collection of 797 Travis CI build logs from 80 GitHub repositories and 29 programming languages.
- Project: scikit-learn / scikit-learn.
- Build ID: 562398767 (failed).
- Dataset path: `LogChunks/logs/Python/scikit-learn@scikit-learn/failed/562398767.log`.
- Dataset annotation: `LogChunks/build-failure-reason/Python/scikit-learn@scikit-learn.xml` identifies a `PackagesNotFoundError` for the requested legacy Python 3.4 and dependency versions.
- Original source: https://zenodo.org/records/3632351 (DOI: 10.5281/zenodo.3632351).
- Dataset license: CC BY 4.0. Credit the LogChunks authors: Carolin Brandt, Annibale Panichella, Andy Zaidman, and Moritz Beller.

The complete downloaded archive is retained at `datasets/LogChunks.zip`. The previous illustrative log is preserved as `data/sample_logs.txt`. The active log is historical research data, not a live feed and not a log from this machine's current test run.
